# Shop-Management-System
A Streamlit web app demonstrating Python Object-Oriented Programming (Inheritance) with role-based classes for store employees, customers, and suppliers, generating dynamic role descriptions through user input.

# Store Role Description App

This is a simple Streamlit web application demonstrating **Object-Oriented Programming (OOP) using Python Inheritance**.

## Features
- Demonstrates class inheritance in Python
- Interactive UI using Streamlit
- Different store roles supported:
  - Manager
  - Cashier
  - Salesperson
  - Regular Customer
  - VIP Customer
  - Supplier

## Technologies Used
- Python
- Streamlit
- Object-Oriented Programming (Inheritance)
1. Run the application

streamlit run app.py
